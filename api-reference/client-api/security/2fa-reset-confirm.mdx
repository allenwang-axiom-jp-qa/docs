## 请求头

<ParamField header="Authorization" type="string" required>
  JWT Bearer token，格式：`Bearer YOUR_TOKEN`
</ParamField>


## 请求体

<ParamField body="code" type="string" required>
  验证码
</ParamField>


## 响应

<ResponseField name="code" type="integer">
  响应状态码，0 表示成功
</ResponseField>

<ResponseField name="message" type="string">
  响应消息
</ResponseField>


<RequestExample>

```bash cURL
curl -X POST 'https://stg-api.beauty-666.com/api/v1/client/2fa/reset/confirm' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Content-Type: application/json'
```

```javascript JavaScript
const response = await fetch('https://stg-api.beauty-666.com/api/v1/client/2fa/reset/confirm', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer ' + token,
    'Content-Type': 'application/json'
  }
});
const data = await response.json();
```

```python Python
import requests

response = requests.post(
    'https://stg-api.beauty-666.com/api/v1/client/2fa/reset/confirm',
    headers={
        'Authorization': f'Bearer {token}',
        'Content-Type': 'application/json'
    }
)
data = response.json()
```

</RequestExample>
