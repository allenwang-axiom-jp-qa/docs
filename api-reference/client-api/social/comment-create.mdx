發表回覆評論（巢狀評論）

參數說明：
- video_id: 影片 ID（必填）
- parent_id: 父評論 ID（必填，用於指定回覆哪條評論）
- content: 評論內容（必填，1-500 字元）

說明：
- parent_id: 直接回覆的評論 ID
- root_id: 由系統自動計算，為討論串的根評論 ID

## 请求头

<ParamField header="Authorization" type="string" required>
  JWT Bearer token，格式：`Bearer YOUR_TOKEN`
</ParamField>
