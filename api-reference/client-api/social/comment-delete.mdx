刪除自己發表的評論

注意：
- 只能刪除自己發表的評論
- 刪除為軟刪除（標記狀態為已刪除）

## 请求头

<ParamField header="Authorization" type="string" required>
  JWT Bearer token，格式：`Bearer YOUR_TOKEN`
</ParamField>


## 响应

<ResponseField name="code" type="integer">
  响应状态码，0 表示成功
</ResponseField>

<ResponseField name="message" type="string">
  响应消息
</ResponseField>

<ResponseField name="data" type="object">
  响应数据
</ResponseField>


<RequestExample>

```bash cURL
curl -X DELETE 'https://stg-api.beauty-666.com/api/v1/social/comment/1' \
  -H 'Authorization: Bearer YOUR_TOKEN'
```

```javascript JavaScript
const response = await fetch('https://stg-api.beauty-666.com/api/v1/social/comment/1', {
  method: 'DELETE',
  headers: {
    'Authorization': 'Bearer ' + token,
    'Content-Type': 'application/json'
  }
});
const data = await response.json();
```

```python Python
import requests

response = requests.delete(
    'https://stg-api.beauty-666.com/api/v1/social/comment/1',
    headers={
        'Authorization': f'Bearer {token}',
        'Content-Type': 'application/json'
    }
)
data = response.json()
```

</RequestExample>

  "code": 0,
