description: '切換影片收藏狀態（Toggle）'
---

切換影片收藏狀態（Toggle）

說明：
- 未收藏 -> 收藏
- 已收藏 -> 取消收藏

返回：
- is_favorited: 當前收藏狀態
- favorite_count: 影片收藏總數

## 请求头

<ParamField header="Authorization" type="string" required>
  JWT Bearer token，格式：`Bearer YOUR_TOKEN`
</ParamField>


## 响应

<ResponseField name="code" type="integer">
  响应状态码，0 表示成功
</ResponseField>

<ResponseField name="message" type="string">
  响应消息
</ResponseField>

<ResponseField name="data" type="object">
  响应数据
</ResponseField>


<RequestExample>

```bash cURL
curl -X POST 'https://stg-api.beauty-666.com/api/v1/social/favorite/1' \
  -H 'Authorization: Bearer YOUR_TOKEN'
```
