獲取某條評論的回覆列表（二級及以下評論）

返回：
- comments: 回覆列表
- total: 总数
- has_more: 是否有更多

## 请求头

<ParamField header="Authorization" type="string" required>
  JWT Bearer token，格式：`Bearer YOUR_TOKEN`
</ParamField>


## 查询参数

<ParamField query="page" type="string" required>
  页码，默認 1
  示例：`1`
</ParamField>

<ParamField query="page_size" type="string" required>
  每頁數量，默認 20
  示例：`20`
</ParamField>


## 响应

<ResponseField name="code" type="integer">
  响应状态码，0 表示成功
</ResponseField>

<ResponseField name="message" type="string">
  响应消息
</ResponseField>

<ResponseField name="data" type="object">
  响应数据
</ResponseField>


<RequestExample>

```bash cURL
curl -X GET 'https://stg-api.beauty-666.com/api/v1/social/replies/1' \
  -H 'Authorization: Bearer YOUR_TOKEN'
```

```javascript JavaScript
const response = await fetch('https://stg-api.beauty-666.com/api/v1/social/replies/1', {

  headers: {
    'Authorization': 'Bearer ' + token,
    'Content-Type': 'application/json'
  }

```

```python Python
import requests

response = requests.get(
    'https://stg-api.beauty-666.com/api/v1/social/replies/1',
    headers={
        'Authorization': f'Bearer {token}',

    }

```
