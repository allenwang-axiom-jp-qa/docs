批量檢查當前用戶是否已收藏指定影片

參數說明：
- video_ids: 影片 ID 列表，逗號分隔（必填）

返回：
- favorited_map: 收藏狀態 Map
  - key: 影片 ID
  - value: true/false（是否已收藏）

範例響應：
{
  "favorited_map": {
    "1": true,
    "2": false,
    "3": true
  }
}

## 请求头

<ParamField header="Authorization" type="string" required>
  JWT Bearer token，格式：`Bearer YOUR_TOKEN`
</ParamField>


## 查询参数

<ParamField query="video_ids" type="string" required>
  影片ID 列表，逗號分隔
  示例：`1,2,3`
</ParamField>


## 响应

<ResponseField name="code" type="integer">
  响应状态码，0 表示成功
</ResponseField>

<ResponseField name="message" type="string">
  响应消息
</ResponseField>

<ResponseField name="data" type="object">
  响应数据
</ResponseField>
