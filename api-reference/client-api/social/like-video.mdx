切換影片按讚狀態（Toggle）

說明：
- 未按讚 -> 按讚
- 已按讚 -> 取消按讚

返回：
- is_liked: 當前按讚狀態
- like_count: 影片按讚總數

## 请求头

<ParamField header="Authorization" type="string" required>
  JWT Bearer token，格式：`Bearer YOUR_TOKEN`
</ParamField>


## 响应

<ResponseField name="code" type="integer">
  响应状态码，0 表示成功
</ResponseField>

<ResponseField name="message" type="string">
  响应消息
</ResponseField>

<ResponseField name="data" type="object">
  响应数据
</ResponseField>


<RequestExample>

```bash cURL
curl -X POST 'https://stg-api.beauty-666.com/api/v1/social/like/video/1' \
  -H 'Authorization: Bearer YOUR_TOKEN'
```

```javascript JavaScript
const response = await fetch('https://stg-api.beauty-666.com/api/v1/social/like/video/1', {

import requests

response = requests.post(
    'https://stg-api.beauty-666.com/api/v1/social/like/video/1',

```
