獲取當前用戶的收藏影片列表

返回：
- videos: 收藏的影片列表
  - video_id: 影片 ID
  - title: 影片標題
  - cover_path: 封面路徑
  - duration: 時長（秒）
  - favorited_time: 收藏時間
- total: 总数
- has_more: 是否有更多

## 请求头

<ParamField header="Authorization" type="string" required>
  JWT Bearer token，格式：`Bearer YOUR_TOKEN`
</ParamField>


## 查询参数

<ParamField query="page" type="string" required>
  页码，默認 1
  示例：`1`
</ParamField>

<ParamField query="page_size" type="string" required>
  每頁數量，默認 20
  示例：`20`
</ParamField>


## 响应

<ResponseField name="code" type="integer">
  响应状态码，0 表示成功
</ResponseField>

<ResponseField name="message" type="string">
  响应消息
</ResponseField>

<ResponseField name="data" type="object">
  响应数据
</ResponseField>
