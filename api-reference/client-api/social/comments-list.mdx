獲取影片的頂層評論列表

排序方式：
- time: 按時間倒序
- hot: 按熱度（按讚數）倒序

返回：
- comments: 評論列表
- total: 總數
- has_more: 是否有更多

## 请求头

<ParamField header="Authorization" type="string" required>
  JWT Bearer token，格式：`Bearer YOUR_TOKEN`
</ParamField>


## 查询参数

<ParamField query="page" type="string" required>
  頁碼，默認 1
  示例：`1`
</ParamField>

<ParamField query="page_size" type="string" required>
  每頁數量，默認 20
  示例：`20`
</ParamField>

<ParamField query="sort_by" type="string" required>
  排序方式：time（時間排序）或 hot（熱度排序）
  示例：`time`
</ParamField>


## 响应

<ResponseField name="code" type="integer">
  响应状态码，0 表示成功
</ResponseField>

<ResponseField name="message" type="string">
  响应消息
</ResponseField>

<ResponseField name="data" type="object">
  响应数据
</ResponseField>
