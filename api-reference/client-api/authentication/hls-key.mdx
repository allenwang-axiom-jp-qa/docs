## 请求头

<ParamField header="Authorization" type="string" required>
  JWT Bearer token，格式：`Bearer YOUR_TOKEN`
</ParamField>


## 路径参数

<ParamField path="job_id" type="string" required>
  Job Id
  示例：`job_123456`
</ParamField>


## 响应

<ResponseField name="code" type="integer">
  响应状态码，0 表示成功
</ResponseField>

<ResponseField name="message" type="string">
  响应消息
</ResponseField>

<ResponseField name="data" type="object">
  响应数据
</ResponseField>


<RequestExample>

```bash cURL
curl -X GET 'https://stg-api.beauty-666.com/api/v1/client/hls-job/job_123456' \
  -H 'Authorization: Bearer YOUR_TOKEN'
```

```javascript JavaScript
const response = await fetch('https://stg-api.beauty-666.com/api/v1/client/hls-job/job_123456', {

    'Content-Type': 'application/json'
```

```python Python
import requests

response = requests.get(
    'https://stg-api.beauty-666.com/api/v1/client/hls-job/job_123456',

        'Authorization': f'Bearer {token}',
        'Content-Type': 'application/json'
    }
)
data = response.json()
```
