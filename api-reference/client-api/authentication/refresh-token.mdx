---
title: '刷新访问令牌'
api: 'POST https://stg-api.beauty-666.com/api/v1/client/refresh_token'
description: '使用refresh_token刷新access_token'
---


## 请求体

<ParamField body="refresh_token" type="string" required>
  刷新令牌
  示例：`refresh_token_string`
</ParamField>


## 响应

<ResponseField name="code" type="integer">
  响应状态码，0 表示成功
</ResponseField>

<ResponseField name="message" type="string">
  响应消息
</ResponseField>

<ResponseField name="data" type="object">
  响应数据
</ResponseField>


<RequestExample>

```bash cURL
curl -X POST 'https://stg-api.beauty-666.com/api/v1/client/refresh_token' \
  -H 'Content-Type: application/json'
```

```javascript JavaScript
const response = await fetch('https://stg-api.beauty-666.com/api/v1/client/refresh_token', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  }
});
const data = await response.json();
```

```python Python
import requests

response = requests.post(
    'https://stg-api.beauty-666.com/api/v1/client/refresh_token',
    headers={
        'Content-Type': 'application/json'
    }
)
data = response.json()
```

</RequestExample>
