模擬第三方支付成功回調 (直接打到 fgpay 服務)

環境變數需求:
- mch_id: 商戶ID
- merchant_key: 商戶密鑰
- deposit_order_no: 充值訂單號
- fgpay_base_url: fgpay 服務地址

pay_status:
- 1: 未支付
- 2: 已支付
- 3: 超時
- 4: 下單失敗

## 请求头

<ParamField header="Authorization" type="string" required>
  JWT Bearer token，格式：`Bearer YOUR_TOKEN`
</ParamField>


## 请求体


## 响应

<ResponseField name="code" type="integer">
  响应状态码，0 表示成功
</ResponseField>

<ResponseField name="message" type="string">
  响应消息
</ResponseField>

<ResponseField name="data" type="object">
  响应数据
</ResponseField>


<RequestExample>

```bash cURL
curl -X POST 'https://stg-api.beauty-666.com/api/v1/fgpay/callback/deposit/notify' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Content-Type: application/json'
```

```javascript JavaScript
const response = await fetch('https://stg-api.beauty-666.com/api/v1/fgpay/callback/deposit/notify', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer ' + token,
    'Content-Type': 'application/json'
  }
});
const data = await response.json();
```

```python Python
import requests

response = requests.post(
    'https://stg-api.beauty-666.com/api/v1/fgpay/callback/deposit/notify',
    headers={
        'Authorization': f'Bearer {token}',
        'Content-Type': 'application/json'
    }
)
data = response.json()
```
