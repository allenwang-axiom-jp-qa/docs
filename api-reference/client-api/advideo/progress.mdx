回報用戶觀看影片的進度

**調用時機**：前端每 5 秒調用一次

**Request Body**:
- user_id: 用戶 ID（必填）
- video_id: 影片 ID（必填）
- watched_sec: 本次觀看秒數（必填，最小值 1）
- product: 產品代碼（必填）

**Response**:
- trigger_ad: 是否觸發廣告
- ad_video_url: 廣告影片 URL（觸發時返回）
- ad_id: 廣告 ID（觸發時返回）
- ad_name: 廣告名稱（觸發時返回）
- ad_thumbnail_url: 廣告縮圖 URL（觸發時返回）
- ad_link_url: 廣告連結 URL（觸發時返回）
- ad_duration: 廣告時長（觸發時返回）
- accumulated_sec: 當前累積觀看秒數

**閾值說明**：
- 預設閾值為 600 秒（10 分鐘）
- 達到閾值後觸發廣告並重置計時器
