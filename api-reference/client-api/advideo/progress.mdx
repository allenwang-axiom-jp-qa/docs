上报用户观看视频的进度

**调用时机**：前端每 5 秒调用一次

**请求体参数**:
- user_id: 用户 ID（必填）
- video_id: 视频 ID（必填）
- watched_sec: 本次观看秒数（必填，最小值 1）
- product: 产品代码（必填）

**响应数据**:
- trigger_ad: 是否触发广告
- ad_video_url: 广告视频 URL（触发时返回）
- ad_id: 广告 ID（触发时返回）
- ad_name: 广告名称（触发时返回）
- ad_thumbnail_url: 广告缩略图 URL（触发时返回）
- ad_link_url: 广告链接 URL（触发时返回）
- ad_duration: 广告时长（触发时返回）
- accumulated_sec: 当前累计观看秒数

**阈值说明**：
- 默认阈值为 600 秒（10 分鐘）
- 达到阈值后触发广告并重置计时器
