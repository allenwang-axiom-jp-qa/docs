## 简介

CMS Client API 提供了完整的客户端功能接口，包括用户认证、视频播放、购买服务、社交互动等核心功能。

### Base URL

```
https://stg-api.beauty-666.com
```

### 认证方式

大部分 API 需要 JWT Bearer Token 认证：

```bash
Authorization: Bearer YOUR_ACCESS_TOKEN
```

## 响应格式

所有 API 响应遵循统一格式：

### 成功响应

```json
{
  "code": 0,
  "message": "success",
  "data": {
    // 响应数据
  }
}
```

### 错误响应

```json
{
  "code": 400,
  "message": "错误描述信息"
}
```

### 常见状态码

| 状态码 | 说明 |
|--------|------|
| 0 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未授权或 Token 失效 |
| 403 | 权限不足 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

## 快速开始

### 1. 获取 Access Token

首先需要登录获取访问令牌：

```bash
curl -X POST 'https://stg-api.beauty-666.com/api/v1/client/login' \
  -H 'Content-Type: application/json' \
  -d '{
    "account": "your_account",
    "password": "your_password",
    "product": "R8888"
  }'
```

### 2. 使用 Token 调用 API

在后续请求中携带 Token：

```bash
curl -X GET 'https://stg-api.beauty-666.com/api/v1/client/profile' \
  -H 'Authorization: Bearer YOUR_ACCESS_TOKEN'
```

### 3. 刷新 Token

Token 过期时使用 Refresh Token 刷新：

```bash
curl -X POST 'https://stg-api.beauty-666.com/api/v1/client/refresh_token' \
  -H 'Content-Type: application/json' \
  -d '{
    "refresh_token": "YOUR_REFRESH_TOKEN"
  }'
```
